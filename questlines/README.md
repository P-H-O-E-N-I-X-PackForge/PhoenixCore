# Conflux questlines (Phoenix Chronicles scaffold)

One chapter per discipline: PHOENIX, SCULK, VOID, SEALED_A, SEALED_B (46 quests). Generated by
`tools/gen_conflux_questlines.py` - edit the tables there and re-run, do not hand-edit the .snbt files.

Install: copy `questlines/conflux/` into the pack's `config/phoenix_chronicles/quests/`.

- Every quest has `enable_if: conflux:flag:<discipline first flag>`, so a player only sees the questline of the
  discipline their team chose.
- Tasks: `conflux_research` (by flag), `dimension`, `structure`, optional `archive_entry`.
- Rewards: xp, items, and `conflux_unlock` flag grants. Each discipline has one quest that grants a restriction-lifting
  flag (e.g. `px_contained_reactions`), the quest-side route to the same recipes the Dispensations trees unlock.
- `archive_entry` ids (`phoenixcore:phoenix_first_flame` etc.) are placeholders until the Archives entries exist.
- Sealed A/B are intentionally thin.

Requires `ConfluxCompat` in Phoenix Chronicles to be wired to `net.phoenix.core.api.ConfluxApi`; it is currently a stub
that reports Conflux as unavailable, so conflux_research tasks and the enable_if gate never pass until it is.
