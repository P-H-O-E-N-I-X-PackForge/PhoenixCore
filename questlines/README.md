# Conflux questlines (Phoenix Chronicles starter chapters)

A hub chapter (`conflux`: the way in, and "Choose a Discipline") and one chapter per discipline: PHOENIX, SCULK, VOID,
SEALED_A, SEALED_B (48 quests in all). Generated by `tools/gen_conflux_questlines.py`: edit the tables there and re-run,
do not hand-edit the .snbt files (or edit them in the Chronicles editor and stop regenerating that chapter).

Install: nothing to do. PhoenixCore copies each chapter into `config/phoenix_chronicles/quests/<chapter>/` the first time
it runs with Chronicles installed (`ChroniclesScaffold`). A chapter whose folder is already there is left alone; delete
the folder to get its starter back. The chapter's name, icon and order are in `<chapter>/<chapter>.json`.

- The hub is always visible. Each discipline is its own category (`categories/<discipline>.yml`, a folder in the sidebar)
  holding its chapter, with `enable_if: conflux:discipline:<id>`: the folder and its chapter are hidden from everyone who
  has not chosen that discipline. (A dev-mode player with "show flag-disabled chapters" on still sees them all.) Every
  discipline quest also has `enable_if: conflux:flag:<discipline first flag>`.
- Tasks: `conflux_research` (by flag), `conflux_discipline`, `dimension`, `structure`, optional `archive_entry`.
- Rewards: xp, items, and `conflux_unlock` flag grants. Each discipline has one quest that grants a restriction-lifting
  flag (e.g. `px_contained_reactions`), the quest-side route to the same recipes the Dispensations trees unlock.
- `archive_entry` ids (`phoenixcore:phoenix_first_flame` etc.) are placeholders until the Archives entries exist.
- Sealed A/B are intentionally thin.

## Triggers PhoenixCore fires (External Trigger tasks)

See `PhoenixChroniclesTriggers`. Use the id as the task's trigger id; the count is how many times it must fire.

| id | when | data |
| --- | --- | --- |
| `phoenixcore:conflux/discipline_chosen` | the team chose a discipline | `discipline` |
| `phoenixcore:conflux/research` | a research node was unlocked | `node` |
| `phoenixcore:conflux/flag` | a research flag was granted | `flag` |
| `phoenixcore:stellar/gas_cloud`, `protostar`, `star`, `black_hole` | the owner's Stellar Forge reached that stage | `stage` |
| `phoenixcore:unique/registered`, `duplicate` | a unique multiblock formed, or a second was tried | `machine` |
| `phoenixcore:placed_item/placed` | an item or block was put on a block face | `item` |

Addons add their own with `ChroniclesLink.registerTrigger(id, description)` and `ChroniclesLink.fire(...)`; both do
nothing when Chronicles is not installed.
